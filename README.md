# doca-installer


please use root to install doca

1- Git clone or download the repository:
```
git clone https://github.com/cpoc-internal/doca-installer
```
Run the shell script to install the doca without accessing the directory, run this as ROOT c885 
```
chmod +x /root/doca-installer/doca-3.1.sh
sudo -u root /root/doca-installer/doca-3.1.sh
```
Run the shell script to install the doca without accessing the directory, run this as ROOT c845
```
chmod +x /root/doca-installer/doca-3.3.sh
sudo -u root /root/doca-installer/doca-3.3.sh
```
